# TUTTI

Object-based immersive audio, controlled from the browser: **https://ytb1124.github.io/tutti/**

The sound runs in **TUTTI Bridge**, a small macOS app (macOS 12 or later): [download](https://github.com/ytb1124/tutti/releases/latest/download/TUTTI-Bridge-macOS.zip).
Unzip, move it to Applications and open it. It is not notarized: the first time, if macOS blocks it, open System Settings › Privacy & Security › Open Anyway.

This repository holds the published website only.
